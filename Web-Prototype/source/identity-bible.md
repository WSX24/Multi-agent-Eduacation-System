# Identity Bible — 智塾机器人

事实源：`source/concept-contract.yaml` 的 `subjects[0]`。本文件锁定
「可验证的身份锚点」、「必须保持不变」与「绝对禁止」三类约束。

来源标注规则：

- `[实测]` = 从当前母版 `source/K0.png` 用工具量出来的数字（可复现）
- `[导出]` = 导出设计里已写死的几何，属于设计契约
- `[决定]` = 本次做出、需在 Pilot 硬门由用户签收的判断

量测工具：`tools/verify_keyframe.py`（背景平涂、脚底接触线、bbox）、
`tools/verify_segment.py`（分段数=肢体分离度、锚点漂移）、
`qa/layout-probe.html` + `qa/landing-geometry.json`（页面侧盒子与地平线的关系）。

## 1. 主体定义

一台圆润的**大头教学机器人**（big-headed compact teaching robot）。
它不是人形、不是机甲、不是写实机器人。头身比接近 1 : 2.4 —— 头非常大且圆，
躯干短而敦实，四肢短粗，整体像一个会走路的圆角方盒。

姿态：**站立**。双脚平踩接触线，双臂自然下垂略外张，头顶舱门闭合，机身直立无倾斜。

## 2. 几何锚点 `[实测] 取自已验收的 source/K0.png，960×960`

坐标系：左上角 (0,0)，右下角 (1,1)。页面 `css/landing.css` 的
`--rig-foot / --rig-eye-y / --rig-eye-w / --rig-hatch-y` 直接读这些值。

| 锚点 | 值 | 说明 |
| --- | --- | --- |
| 脚底接触线 | **y = 0.899** | 页面的 `--rig-foot` 就是它（`verify_keyframe.py` 实测） |
| 主体水平中心 `cx` | **x = 0.4995** | 全片不变；偏差超过 ±0.005 即返工 |
| 主体整体 bbox | x 0.211–0.787，y 0.120–0.899 | 横向占宽 **0.577**，纵向占高 **0.779** |
| 头顶 | y = 0.120 | |
| 头顶舱门缝 | y 0.171–0.178，x 0.442–0.460 | 页面的 `--rig-hatch-y: 17%` 落在这里 |
| 眼区（左眼） | x 0.405–0.470，y 0.239–0.304 | 该盒平均亮度 70.6，四周 141–203 —— 实测最暗区即眼 |
| 眼区（右眼） | x 0.540–0.597，y 0.239–0.304 | 平均亮度 95.0；`--rig-eye-y: 27%`、`--rig-eye-w: 19%` |
| 手臂最外沿 | 左 x 0.211 起，右至 x 0.787 | 悬停版曾张到 0.824（4:3 才装得下）；站姿不需要 |
| 双腿 | y 0.75–0.899，两腿分离 | 分段 @0.80 = 2 |

**肢体分离度是硬约束。** 用户明确要求「肢体能摆动」，视频模型要有空间把手臂
移开才不会糊成一团。当前母版在 y 0.45/0.55/0.65 三行都是 **3 段**（左臂｜躯干｜右臂）。
**每张关键帧、每段成片都要单独复测分段数**，手臂与躯干粘连的帧一律返工
（seg-01-charge 就是栽在这一条上，见 `qa/seg-01-verify.json`）。

**推进器**：本版形象的手上没有任何喷口结构，也没有火焰层。旧悬停版的
`.rig-thrust` 火焰已整块删除（无飞行段就不点火）。

## 3. 色彩锚点 `[实测] 取自已验收的 source/K0.png`

| 角色 | 色值 | 去背景后面积 | 用途 |
| --- | --- | --- | --- |
| 壳体主色 `shell` | `#6080A0` (96,128,160) | 4.93% | slate 蓝，面积最大的单一色 |
| 壳体中间调 | `#7080A0` / `#8090A0` / `#608090` | 各 2.2–2.4% | 连续过渡，说明是**体积塑形**而非平涂 |
| 银灰面板 `panel` | `#B0B0B0` / `#C0C0C0` / `#A0A0B0` | 10.4% | 面板与高光面 |
| 深蓝重点色 `accent` | `#204878` / `#285080`（家族共约 2.8%） | 2.8% | 面部平板、眼部胶囊、细节 |
| 轮廓线 | 最暗实测量到 (0,0,8) | — | 近黑勾边 |
| 主体占画布面积 | 21.9% | — | 其余 78.1% 是纯白 |

**色相家族：slate 蓝灰 + 银灰 + 深蓝重点色。全图紫色像素 = 0（已逐像素统计），
不得引入紫色。**

**关键约束：主体不能是大面积纯白或接近纯白。** 页面背景是纯白，且页面用
`mix-blend-mode: multiply` 合成这张图，因此接近白色的表面会直接消失。
银灰面板 `#C0C0C0` 已是可接受的亮面上限，不允许出现比它更亮的大面积表面。

## 4. 材质与光照 `[决定]`

- 哑光注塑壳体，粗糙度中等，**不做镜面反射、不做金属拉丝、不做镀铬**。
- 单一主光来自画面上方略偏左（约 −20° 方位、35° 仰角），冷白。
- 一盏暖色补光来自画面右下方，强度约为主光的 0.35，只提亮壳体转折。
- 接触阴影**不属于素材**：页面用 `.rig-shadow` 画地面投影。素材内不得有落地阴影、
  不得有地面、不得有环境反射。
- 无景深、无运动模糊、无镜头光晕、无粒子、无体积光。

## 5. 画风 `[实测] 与当前母版一致`

**当前母版的实际画风是「现代西方动画长片」的软体积塑形，不是平涂厚描边的
平面卡通。** 这一点必须写清楚，因为它是被写进生成提示词里的：
`source/prompt-K0.txt`（形象定义）与 `source/prompt-K0-ref.txt`（锁定参考图的改写版）。
两者都**明确禁止**「flat cel shading、硬边平涂阴影、统一粗描边、矢量剪贴画感」。

- **体积**：每个弧面都有连续过渡，转折处有克制的环境光遮蔽；阴影边缘不虚化，
  但不是两级色块。
- **高光**：头顶壳体与肩帽各一道宽的柔和高光，每只眼睛一个清晰的高光点。
  不做镀铬、不做镜像反射。
- **表面**：哑光涂装金属，带极细的颗粒；关节与鞋底用更暗更软的材料。
  下半身允许一点友好磨损，不许脏、不许破损。
- **卡通化形体**：头身比与第 2 节的全部锚点数值一起锁定，保持四肢短粗、末端圆润。
- **细节克制**：不做细碎发光线条、不做满身电路纹理、不做机械线缆、不做赛博霓虹、
  不做 hyperdetailed 8k 噪点。细节只服务于「这是一台能吞书的教学机器」这一个焦点。
- **眼睛是表情器官**：深蓝胶囊 + 白色高光点，睑线在动作中允许压扁（眯眼 / 受力）。
- **不允许**：写实 CGI、3D 渲染、油画、像素画、动漫、赛博朋克、军事机甲。

> 历史记录：本文件早期版本写的是「卡通风格 + 4px 统一描边 + cel-shading 两级明暗」，
> 那是对现有位图画风的主观描述，与后来实际采用的母版（现代动画风格）不一致，
> 已按实测与提示词改正。

## 6. 绝对禁止（任一出现即返工）

1. **身份漂移**：头身比、头部尺寸、眼部位置与形状、舱门位置在关键帧与片段之间改变。
2. **增删部件**：不得新增或删除手指、屏幕、天线、轮子、背包、推进器、额外舱门。
3. **数量错误**：全片恒为 1 台机器人。不得出现第二台、不得出现镜像分身。
4. **风格漂移**：不得变成写实 CGI、3D 渲染、油画、像素画、赛博朋克。
5. **背景残留**：`background_owner = video`（见 Concept Contract）——背景与主体
   同在一张平涂纯白里烘焙，**不使用 alpha 通道**。成品不得带任何地板、地面线、
   渐变、暗角、阴影、光晕、棋盘格或色块；边距必须持续是纯白（`verify_segment.py`
   的「边距 min」列 ≥244）。
6. **紫色**：素材内不得出现 `#a855f7` 家族的任何紫色。
7. **文字**：不得出现任何文字、数字、字幕、水印、边框、UI 控件。
8. **摄影机**：锁定机位、锁定焦距、锁定缩放、锁定中心锚点。不得推拉摇移、
   不得透视呼吸、不得景深变化。
   （**为什么必须锁死**：分镜头里的弧移、推近、升降全部由页面程序用 2D 实现，
   素材内一旦自带位移，两层会叠加成双倍位移，落地会「滑」。）
9. **锚点漂移**：脚底接触线 y=0.899 与水平中心 x=0.4995 在每一帧完全不变。
   `verify_segment.py` 的脚底漂移上限 0.015 是硬门。
10. **悬停**：待机姿态不得浮空、不得有纵向呼吸位移、不得点火。
    用户 2026-09-25 明确取消（Concept Contract 决定 #7）。
