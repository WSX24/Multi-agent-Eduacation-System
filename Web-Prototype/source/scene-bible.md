# Scene Bible — 一本书的光

事实源：`source/concept-contract.yaml` 的 `scene` 与 `style`。本文件锁定
「这个一镜到底发生在什么样的世界里」，以及每一条约束的**可验证判据**。

生成服务是 Magic Hour AI（`api.magichour.ai`），不是 Agnes。工具是
`tools/magichour_job.py`。

---

## 0. 一句话

**一张近白略暖的台面上摊着一本米色的书，右后方悬浮着一颗深蓝灰的多面体；
知识从书里化作一团柔和的光，飘过去把它点亮。** 没有第二个主体、没有第二种彩色。

---

## 1. 为什么世界长这样（先读这一节，否则会把它当审美偏好改掉）

这个世界的**首要约束不是好看，是模型守得住**。

在同一个生成服务上，先用「一个书架、一排书脊」试过两轮，都失败：

| 题材 | 5 秒后的结构相关（1.0 = 骨架一致） |
| --- | --- |
| 一排书脊（细密高频结构） | **0.095** —— 糊成一团色块 |
| 一本书（几块大形状） | 画面守得住，光的方向也守得住 |

480p 的小模型守不住细密结构。所以这个世界的全部设计都服从一条：
**降低画面信息密度**——

- 只有**两件物体**：一本摊开的书、一颗多面体。没有书架、没有成排的书、没有房间。
- 书是**两块大弧面 + 一条中缝**，不是一堆书脊。
- 光是一**团**柔和的雾、一**道**收束的光带，绝不是「一道道细如发丝的光」。
- 背景是一整片纯净的近白台面，**不画任何东西**。

这不是妥协，是这套参数下唯一能成立的画法。改之前请先跑一次 Pilot。

---

## 2. 材料

| 材料 | 定义 | 出现范围 | 禁止 |
| --- | --- | --- | --- |
| **台面 / 墙** | 近白、略暖的素面，约 `#EFEDE8`，无纹理、无家具、无窗、无阴影投射 | 全片，唯一的背景 | 不许出现房间结构、地板线、家具、装饰；不许压成中灰或褐 |
| **书** | 摊开的一大本书，米白 / 奶白的厚纸页，中间一道柔和折痕，页面上几行**细灰的、不可读的**字迹。哑光 | 左下部，全片 | 不许合上、不许翻页、不许移动、不许改变形状；不许出现可读文字 |
| **多面体（智能体核心）** | 深蓝灰、哑光的切割多面体，约拳头大，悬浮在矮台座上方。切面清晰，中间一道细缝 | 右后方，全片 | 开场不发光、不移动；结尾从内部透出淡紫白光，光晕**紧贴表面**、很短距离内消失 |
| **光** | 淡紫白（`#a855f7` 家族偏白的那一端）。形态是**弥散的光雾**与**收束的光带**，不是细线 | 从书升起 → 飘向核心 → 汇入核心 | 不许硬光束、激光、gobo、镜头光晕、体积光柱；不许铺满画面；不许照亮墙面与台面 |

**面积纪律**：紫色任何一帧不超过画面的 **8%**。它是光，不是主色。

## 3. 可验证判据（`tools/verify_scene.py --profile book-light`，逐帧）

| 检查项 | 门限 | 实测（编译产物） |
| --- | --- | --- |
| 亮纸占比（>200 且 sat<0.15） | ≥ 60% | 89.2 – 95.8% |
| 亮度 95 分位 | ≥ 235 | 242 – 245 |
| 平均亮度 | ≥ 210 | 226 – 235 |
| 紫色面积 | ≤ 8% | 0.32 – 3.55% |
| **褐色面积**（暖 + sat>0.35 + 亮度<160） | ≤ 3% | 0 – 1.82% |
| 极暗像素（min<12） | ≤ 1.5% | 0 – 0.07% |
| 过曝像素（min>250） | ≤ 2% | 0.01 – 0.05% |
| 绿 / 青 / 红（sat>0.18） | 各 ≤ 1% | 0% / 0% / 0.01% |
| 中轴 / 走道 | **不适用** | 本片没有构图中轴约束 |

### 为什么暖色要换一把尺子（门限校准记录）

第一版沿用纸世界的门限（「禁止橙黄色相，各 ≤1%」），实测**直接判死**：
前 2.5 秒的「未分类彩色」有 5.0 – 7.8%。复核后确认**是尺子错了，不是画面错了**：

| 实测 | 数值 |
| --- | --- |
| 画面落在暖色相（15–70°）的比例 | **81.8%** |
| 其中饱和度 < 0.10 的 | 71.3% |
| 「暖 + 淡（sat<0.25）+ 亮（>190）」 | 77.7% |
| **「暖 + 高饱和（>0.35）+ 暗（<160）」（= 褐色）** | **1.20%** |

也就是说：这个世界的主体（米色的书）和背景（略暖的台面）本来就落在暖色相里，
用「禁止暖色」去卡它等于禁止它自己的材质。

正确的工具是区分**淡米色**与**褐色**：
- 淡米色 = 暖 + 低饱和 + 高亮度 → 合法材质
- 褐色 = 暖 + 高饱和 + 低亮度 → 要么是深色木头，要么是画面被压暗

所以新增 `book-light` 档位：不禁止暖色相，只禁 `暖 + sat>0.35 + 亮度<160` 的褐色，
上限 3%。这一条在书架上那版**真的抓到了问题**（深棕占 7.06%），在这里只有 1.2%。

## 4. 光的行为（本片的叙事）

| 阶段 | 画面 |
| --- | --- |
| 起 | 书页上有极淡的微光，核心是暗的、安静的 |
| 升 | 柔和的淡紫白光雾从书上升起 |
| 飘 | 光雾缓慢向右朝核心移动，形态保持弥散、体积不膨胀 |
| 汇 | 光收成一道较细的光带，从核心左侧流进去 |
| 亮 | 核心的切面从内部亮起，中缝成为一条明亮细线，光晕紧贴表面 |

**关键**：光的紫色面积不应随时间单调膨胀成团。实测失败版会涨到 9.26% 并堆成紫云；
合格版峰值 3.46%、收尾 3.55%，且水平重心守在核心一侧。

## 5. 绝对禁止（任一出现即返工）

1. **书架 / 成排的书 / 书脊**。这是本片已经失败过两次的题材，不要加回来。
2. **细如发丝的光线**。细密结构在 480p 下必然消失或被糊成一团。
3. **褐色**（暖 + 高饱和 + 暗）。这是「木色被画深」或「画面被压暗」的信号。
4. **第二种彩色**：红、橙、黄、绿、青一律不许。
5. **可读文字**。书页上的字必须是纯装饰性的、不可读的线。
6. **镜头运动**：除极缓向前推近外，不许摇、不许移、不许变焦抽动、不许重新构图。
7. **画面变暗 / 偏色 / 暗角 / 模糊 / 重影 / 闪烁**。
8. **霓虹、赛博朋克、电路、全息、屏幕、科幻机械、塑料 AI 噪点**。
9. **多余物体、第二本书、第二颗核心、手、人**。
10. **视频水印**（见第 6 节）。
