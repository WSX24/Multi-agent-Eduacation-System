## 0. 一句话

**往下滚 = 你在推一台摄影机，同时也在落笔。** 它从一张完整的空白纸推进到纸的
内部，再拉远收束，把整幅一笔画收进画面。

全片只有一个运动主体：**一条自己生长的墨线的前端**。没有角色、没有道具、
没有第二种彩色。不切、不停、不反向回放。

---

## 1. 为什么前三版的失败，在这一版结构上不会发生

前三版的失败模式全部来自同一件事：**某个主体必须跨越多段/多尺度保持一致。**
参考图会牵引色调与构图（三次 K0 尝试里，暖褐与中轴偏右**只在参考图在场时**
出现）；角色身份会漂移；五级尺度要各锁一套风格。

一条自己生长的墨线把这件事从"靠约束压制"变成"结构上不存在"：

| 前三版的失败 | 这一版为什么不会发生 |
| --- | --- |
| 中轴偏右（方向 2 三次都栽） | **自锚定**：锚点是笔尖与纸心的加权点，由运动定义，不需要逐帧维持构图 |
| 跨尺度风格漂移 | **自相似**：线在五个尺度上都是线。放大只是把同一个形状看得更近 |
| 身份漂移 | **无身份**：没有脸、没有部件、没有道具 |
| 不可逆（旧的起跳落地） | **可逆**：笔画往回走就是擦除，推轨往回走就是拉远。两者物理上都成立 |
| 多段接缝 | **无接缝**：全片只有一条 path。帧链的两道硬门按构造不适用 |
| 参考图拖色偏 | 不需要参考图 |
| 移动端 9:16 缺口 | **不存在**：没有固定画幅的媒体资产，桌面与移动同一套实现 |

**代价（诚实记账）**：观感是"极漂亮的线描动画"，不是电影。没有景深、
没有体积光、没有实拍材质。唯一的补救选项见 §6。

## 2. 世界：纸与墨

一句话：**一张白纸，和落在它上面的一条墨线。**

纸由两层合成——**纤维层**是程序生成的无缝分形（fBm），恒不透明、平铺随缩放，
所以放大时纤维真的变大；**宏观层**是 AI 生成的纸材质板（已调色），提供大面积
肌理，s>1.2 之后淡出。稿纸格的格距在世界坐标里恒定，像真的横格纸。

青色纪律：紫色只在河道那一段出现（路径 66% 之后），面积 ≤8%。

完整约束与判据见 `source/scene-bible.md`。

## 3. 笔画路线

一笔画，不抬笔。消失点 (1200,800) 就是纸心。

```
起笔 → 透视房间（六条轮廓线）→ 远端黑板 → 左墙的窗
     → 左排三张课桌 → 右排三张课桌 → 右墙三层书架
     → 讲台 → 摊开的书（两页 + 书脊 + 两行不可读的字）
     → 从书页落下的河道（此处开始转紫）→ 四道工序 → 收笔回环
```

**四道工序**（与 `#agents` 一节同序）：裁纸排大纲 / 红笔批改 / 错题落入纸格 /
卡片插入刻度。

课桌按一点透视排：底边 y 分别为 1220 / 1100 / 980，宽度 363 / 259 / 155，
中间留出向消失点收窄的走道。这是"画面丰富"的主要来源——按透视规律加物件，
不是加杂线。

---

## 4. 运镜

指数缩放 = **匀速推轨**（线性缩放会让推近在透视上先快后慢，读起来"不对"）。

```
s0 = 0.64   → sMax = 1.6（进度 62% 处最深）→ sEnd = 0.70（收束）
```

锚点 = 笔尖与纸心的加权点：前段笔尖权重 0.75（留四分之一余量给整幅构图），
进度 80% 之后过渡到完全纸心。

**为什么最深只到 1.6×**：v4 第一版用 4.6×，p=0.62 时画面只装得下整幅画的
348×196 单位，绝大部分构图在画面外，墨覆盖率只有 1%——读起来是"空纸 + 一条线"。
这是"画面不够丰富"的直接原因。

滚动行程 **600vh**（6 屏）。一镜到底的手感全在这个值上。

## 5. 谁做什么

| 内容 | 谁做 |
| --- | --- |
| 墨线的路径、生长、摄影机 | 程序（读 `source/line-spec.js`） |
| 纸的纤维（分形） | 程序（`tools/make_fiber.py`，确定性、无缝自检） |
| 纸的大面积肌理与折痕 | 生成（1 张材质板，`tools/grade_plate.py` 调色） |
| 稿纸格、光斑、紫色河道 | 程序 |
| 字标、CTA、进度条 | 程序，在画布之外；画面里**不得**出现任何可读文字 |

**本片不产生任何动画媒体**：1 张材质板 + 1 张程序生成的纤维板，其余全是矢量与
CSS。所以没有编码体积、没有帧链接缝、没有固定画幅。

## 6. 可选增强：墨渗进纸纤维（需你决定）

唯一可能用到生成媒体的地方：在"墨线钻进纸里"那一刻，用 `concepts.md` 的
**实体遮挡转场**——墨灌满整个画面（100% 遮挡）→ 底下播一段生成的
「墨渗进纸纤维」实拍质感 → 墨退开，露出下一段线。

只有**一个**位置用生成素材，没有链式接缝风险，换来真实的材质厚度。
它是 `background_owner=video` 的短片段，按 `baked-video` 单独预算，
不进入本条时间轴。

不加：全片零视频生成，观感是"极漂亮的线描动画"。

## 7. 退出与降级

| 条件 | 行为 |
| --- | --- |
| `prefers-reduced-motion: reduce` | 不绑定滚动，直接渲染最终状态（整幅完成的画 + 收笔光点），停止 rAF 与光斑视差 |
| 移动端 | 与桌面同一套实现。纸是无限平铺、线是矢量，随视口自适应，**不需要第二套媒体** |
| 弱网 | 只有两张静态材质。任一加载失败则回退为无材质的纯色纸（`#faf8f4`），线照常绘制 |
| 快速反向滚动 | 纯函数重算，无解码队列、无粘滞 |
| 页面切后台再回来 | 以当前滚动位置恢复，不重播 |

## 8. 需要你签收的三件事

1. **底稿默认值**（`?under=lead|full|off`，现为 `off`）。
   `full` 让每一帧都带完整构图的淡铅笔幽灵（p=0.62 处结构量 1.00% → 1.17%），
   每一帧都不空；代价是整幅构图从第一帧就隐约可见。
   对照图：`qa/line-prototype-sheet.png`（上半 off / 下半 full，共 12 格）。
   **这一项 ASCII 判不了**（降采样会把细铅笔线平均掉），只能你看。
2. **滚动行程 600vh、最深缩放 1.6×。** 缩深与"画面丰富"是直接的此消彼长：
   再收就不像推轨，再放就回到"空纸 + 一条线"。
3. **可选增强**（§6）要不要做。
