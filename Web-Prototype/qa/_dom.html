四个 AGENT · 一条流水线

一间教室里，四个角色各管一段。

它们不是四个聊天框，而是四条流水线：每一段产出都会流向下一个 Agent，也会回流给上一个。

T / TEACHER

教师 Agent

生成学习计划与教学任务。从大纲开始，把内容串成单元与章节；不一次性铺满全部讲解与视频，因为你随时可能调难度。

  • · 大纲 → 单元 → 章节
  • · 每单元小练习
  • · 每章节一次测验
A / ASSISTANT

助教 Agent

批改提交的答案，产出学情报告与薄弱点分析，共享给教师 Agent 调整后续任务；同时把错题归纳好，交给答疑 Agent。

  • · 自动批改
  • · 薄弱点分析 → 教师
  • · 错题归纳 → 答疑
Q / Q&A

答疑 Agent

收纳整本错题库。错题一键解答，也可以单独对话；拿到错题后还能检索或生成同类型题目，让你在同一条沟里摔第二次的机会变小。

  • · 错题一键解答
  • · 单独对话
  • · 生成同类型题
C / COACH

督学 Agent

采集学习时长、做题量、正确率与提问情况，判断拖延倾向；按艾宾浩斯遗忘曲线排复习计划，每天在首页留一句正能量，定期出学习状态简报。

  • · 行为数据采集
  • · 遗忘曲线复习
  • · 每日一句 / 简报
学习闭环 · 从大纲到复习

一条从大纲走到复习的闭环。

01

生成课堂

选教师形象、LLM 模型与教学周期，先出一份大纲。

02

按需生成

讲解与视频随进度生成，难度随时微调。

03

练习与测验

每单元小练习，每章节一次测验，答完即交。

04

批改与学情

助教给分、定位薄弱点，把错题送进错题库。

05

答疑与复习

一键解答错题，按遗忘曲线排回复习计划。
