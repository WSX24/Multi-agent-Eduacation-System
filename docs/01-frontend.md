# 前端阶段记录与使用指南

## 1. 当前前端概况

前端项目位于 `frontend/`，使用 Vue 3、TypeScript、Vue Router 和 Vite。账号注册、登录、令牌刷新、获取当前用户和退出登录已接入 Django；课程和大模型流程仍为演示数据或占位。

## 2. 已完成的页面与流程

### 首页与登录注册

- 首页展示平台介绍和入口。
- 登录页提供登录、注册两种表单样式切换。
- 登录使用邮箱和密码校验真实账号；注册需要邮箱验证码、密码、确认密码和同意条款，成功后自动进入工作区。
- 注册密码至少 8 位且包含数字；后端还会拒绝常见密码、纯数字密码，以及与邮箱信息过于相似的密码。前端当前提示只写了长度和数字要求，尚未展示后端的全部限制。
- 注册页的“发送验证码”按钮会调用后端接口，显示发送结果与重发倒计时；验证码由 Django 输出到运行后端的终端，不会发送到邮箱。
- 工作区需要登录；刷新页面会调用 `/api/accounts/me/` 恢复用户信息，访问令牌过期时会尝试刷新。侧边栏显示当前邮箱并提供退出登录。
- 暂未实现验证码登录和找回密码，登录页已隐藏这两个入口。

### 生成课堂

- 用户可以在对话框里描述希望学习的主题和目标。
- 前端会模拟生成课程大纲和配套材料，展示单元及其小节。
- 可以选择学习周期、学习起点和模型偏好；目前这些设置只影响演示界面。
- 点击“保存到我的课程”后，课程会保存到当前浏览器。

### 我的课堂

- 显示内置的“高中物理必修一”课程，以及当前浏览器中保存的生成课程。
- 课程卡片显示封面、课程名称、学习目标、学习周期、类型和创建时间；目前课程类型统一显示“个性化课堂”。
- 支持按关键词搜索课程内容，并按学习周期筛选。

### 课程详情与小节学习入口

- 课程详情依次展示课程概述、学习目标和课程大纲。
- 大纲按照“单元 → 小节”呈现，每个小节前有完成状态标记：橙色“未”代表未完成，绿色勾代表已完成。
- 点击小节会进入对应的课堂学习页面。
- 课堂学习页面目前是占位页面，后续可接入讲义、课堂脚本和互动内容。演示状态还不会根据实际学习行为自动更新。

## 3. 如何启动

在项目根目录 `Multi-agent-Eduacation-System` 下打开终端，执行：

```powershell
cd .\frontend
npm install
npm run dev
```

首次启动时执行 `npm install` 安装依赖；之后日常启动通常只需要：

```powershell
cd .\frontend
npm run dev
```

账号功能还需要按 `backend/README.md` 安装后端依赖、迁移数据库并启动 Django。启动成功后，前端终端会显示本地访问地址，通常是 `http://localhost:5173/`。停止开发服务器时，在运行服务器的终端按 `Ctrl+C`。

项目还提供以下命令：

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 启动本地开发服务器 |
| `npm run build` | 执行 TypeScript 检查并构建前端 |
| `npm run preview` | 本地预览构建后的前端 |

## 4. 推荐体验顺序

1. 启动 Django 与 Vue，打开首页进入注册页，获取验证码并创建账号；已有账号可直接登录。
2. 在“生成课堂”里输入一个主题，例如“我想学习高中物理的牛顿运动定律”，发送后查看模拟生成的大纲和材料。
3. 点击保存，进入“我的课堂”。
4. 打开课程卡片，查看概述、目标和大纲。
5. 点击任意小节，进入该小节的课堂学习占位页面；使用“返回课程大纲”回到课程详情。

## 5. 前端代码与演示数据位置

| 内容 | 文件 |
| --- | --- |
| 首页、登录注册、生成课堂、我的课堂、课程详情和小节学习页面 | `frontend/src/views/` |
| 工作区侧边导航与页面框架 | `frontend/src/components/AppShell.vue` |
| 路由配置 | `frontend/src/router/index.ts` |
| 账号 API 请求与当前会话 | `frontend/src/api/accounts.ts` |
| 课程数据类型、物理必修一示例、浏览器存取逻辑 | `frontend/src/data/demoCourses.ts` |
| 生成课堂的模拟对话和课程生成逻辑 | `frontend/src/views/GenerateView.vue` |
| 全局及原型复用样式 | `frontend/src/styles/`、`frontend/src/style.css` |

“高中物理必修一”的固定示例数据在 `demoCourses.ts` 的 `physicsDemoCourse` 中。由生成页面保存的课程使用浏览器 `localStorage`，存储键为 `zhishu-demo-courses`；数据只在当前浏览器中，不会同步到其他设备或用户。

课程完成状态使用 `completedLessons` 保存，小节编号采用“单元号.小节号”的格式，例如 `1.1`。旧版本地数据中的字符串单元和单元级完成状态会在读取时转换为当前的小节结构。

如需清除当前浏览器保存的演示课程，可以在浏览器开发者工具 Console 执行：

```js
localStorage.removeItem('zhishu-demo-courses')
location.reload()
```

这只会清除该浏览器内保存的生成课程；代码中的物理必修一固定示例仍会显示。

## 6. 当前限制与后续衔接

- 账号已接后端；当前验证码只输出到 Django 终端，用于本地开发，不会投递到邮箱，也不需要配置发件邮箱。令牌保存在当前标签页的 `sessionStorage`，关闭标签页后需重新登录。
- 课程大纲和课件文件名为前端模拟结果，没有调用大模型或生成真实文件。
- 已保存课程使用浏览器本地存储，没有接 Django 数据库或跨设备同步。
- 小节页面已经有独立路由和入口，实际讲授内容、学习记录及完成状态更新尚未接入。
- 当前课程都显示为“个性化课堂”；社区课程类型暂未实现。

下一步可替换 `GenerateView.vue` 中的模拟生成逻辑和 `demoCourses.ts` 中的本地存取逻辑，再为课程保存和小节学习补充 API。
